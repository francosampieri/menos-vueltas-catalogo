## Uso

- Google Sheets es la fuente operativa de verdad: no cambiar estructuras, fórmulas ni datos sin aprobación explícita.
- B2C está activo; B2B está visible pero comercialmente en preparación.
- Antes de tocar precios, promociones, datos personales, estructura de Sheets, Apps Script o seguridad, leer los documentos relacionados y explicitar el impacto.
- No usar registros reales de clientes ni información personal en documentación, pruebas, ejemplos o commits.
